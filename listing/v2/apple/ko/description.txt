Bimir Lock은 비밀번호를 암호화해 내 iPhone이나 iPad에만 보관하는 오프라인 비밀번호 관리자입니다. 만들어야 할 계정도, 믿고 맡겨야 할 클라우드도, 광고도 없습니다. 로그인 정보는 한 번만 저장하면 PIN이나 Face ID로 열고, 자동 완성으로 입력할 수 있습니다.

■ 비밀번호는 내 기기 안에
• 비밀번호와 메모는 저장하기 전에 AES-256-GCM으로 암호화
• 암호화 키는 iOS Keychain에 이 기기 전용으로 보관되며, 동기화되지 않습니다
• 회원가입도, 이메일도, 서버도 없으니 누군가 뚫고 들어올 계정 자체가 없습니다
• 비행기 안에서도, 해외에서도, 모바일 데이터를 꺼도 오프라인으로 모든 기능 사용 가능
• 광고 없음, 분석 도구 없음, 추적 없음

■ 나만 열 수 있습니다
• 저장한 비밀번호는 6자리 PIN으로만 열 수 있고, 원하면 Face ID나 Touch ID도 쓸 수 있습니다
• 123456, 111111 같은 쉬운 PIN은 사용할 수 없습니다
• PIN을 7번 연속 틀리면 키패드가 잠깁니다: 30초, 이후 1분, 5분, 15분
• PIN 오입력 알림에서 모든 잠금 기록을 확인하고, PIN을 추측한 사람의 사진을 찍을 수도 있습니다(선택 사항, 사진은 기기에만 보관)
• 표시한 비밀번호는 30초 후 다시 가려지고, 복사한 비밀번호는 30초 후 클립보드에서 지워집니다

■ 강력한 비밀번호를 대신 만들어 드립니다
• 8~64자 비밀번호 생성기, 숫자와 기호 포함 여부 선택
• l, I, O, 0처럼 헷갈리기 쉬운 문자는 제외
• 모든 비밀번호에 강도 표시
• 이미 저장한 비밀번호를 다시 쓰려고 하면 미리 경고

■ 비밀번호 점검
• 약한 비밀번호와 여러 사이트에서 함께 쓰는 비밀번호를 찾아냅니다
• 무엇부터 고쳐야 할지 보여 주고, 항목마다 변경 버튼 제공
• 점검은 기기 안에서만 이루어지며, 어디로도 전송되지 않습니다

■ 자동 완성
• Bimir Lock은 Safari와 다른 앱에서 비밀번호 자동 완성 앱으로 사용할 수 있습니다
• iPhone 설정의 '자동 완성 및 암호'에서 켜세요
• Face ID, Touch ID 또는 기기 암호로 확인하기 전에는 아무것도 입력되지 않습니다

■ 직접 관리하는 백업
• 백업 전용 비밀번호로 잠근 암호화 파일 하나로 백업(Argon2id + AES-256-GCM)
• 보관 위치는 자유롭게: 파일 앱, iCloud Drive, 컴퓨터 등
• 새 iPhone에서 복원하면 없는 항목만 추가하고, 아무것도 삭제하지 않습니다

■ 차분하고 쉬운 사용
• 검색과 첫 글자 아이콘이 있는 깔끔한 목록
• 입력하는 동안 사이트 이름 추천
• 아이디 칸이 이메일, 전화번호, 고객 번호, Wi-Fi 네트워크 이름에 맞춰 바뀝니다
• 라이트 테마와 다크 테마
• 앱을 열 때마다 보안에 관한 짧은 명언 표시
• 일상 메모를 위한 메모 공간(메모 공간은 암호화되지 않으니, 비밀 정보는 각 비밀번호의 암호화된 메모에 적어 두세요)

■ 이런 기능은 없습니다
클라우드 동기화도 계정도 없기 때문에 비밀번호 금고는 기기 한 대에만 있습니다. 백업 파일을 안전한 곳에 보관해 주세요. Bimir Lock은 유출된 비밀번호 목록과 대조하지 않으며, 2단계 인증(2FA) 코드도 만들지 않습니다. 앱 화면은 현재 영어로 제공됩니다.

무료이며 광고와 인앱 결제가 없습니다. 네팔 포카라의 1인 개발자가 만들었습니다.
