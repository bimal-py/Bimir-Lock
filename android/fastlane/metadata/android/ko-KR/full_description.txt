Bimir Lock은 Android용 오프라인 비밀번호 관리자입니다. 비밀번호를 암호화해 내 휴대폰에만 보관하는 비밀번호 금고이자 비밀번호 저장 앱이에요. 계정도, 클라우드도, 광고도, 구독도 없습니다. 비밀번호는 한 번만 저장해 두면 PIN이나 지문으로 열고, 지금 쓰고 있는 앱에 바로 자동 완성할 수 있습니다.

■ 계정이 필요 없는 비밀번호 관리자
• 오프라인으로 작동: 비밀번호 금고는 누군가의 서버가 아니라 이 휴대폰 안에 있습니다
• 회원가입도 이메일도 필요 없으니, 누군가 뚫고 들어올 계정 자체가 없습니다
• 비밀번호와 메모는 저장하기 전에 AES-256-GCM으로 암호화
• 암호화 키는 Android Keystore에 보관되며 기기 밖으로 나가지 않습니다
• 광고 없음, 분석 도구 없음, 추적 없음

■ 비밀번호는 나만 열 수 있습니다
• 저장한 비밀번호는 6자리 PIN으로만 열 수 있고, 원하면 지문이나 얼굴 인식도 쓸 수 있습니다
• 123456, 111111 같은 쉬운 PIN은 사용할 수 없습니다
• PIN을 7번 연속 틀리면 키패드가 잠깁니다: 30초, 이후 1분, 5분, 15분
• PIN 오입력 알림에서 모든 잠금 기록을 확인하고, PIN을 추측한 사람의 사진을 찍을 수도 있습니다(선택 사항, 사진은 휴대폰에만 보관)
• 표시한 비밀번호는 30초 후 다시 가려지고, 복사한 비밀번호는 30초 후 클립보드에서 지워집니다

■ 비밀번호 생성기
• 8~64자의 강력한 비밀번호 생성, 숫자와 기호 포함 여부 선택
• l, I, O, 0처럼 헷갈리기 쉬운 문자는 제외
• 모든 비밀번호에 강도 표시
• 이미 저장한 비밀번호를 다시 쓰려고 하면 미리 경고

■ 비밀번호 점검
• 약한 비밀번호와 여러 사이트에서 함께 쓰는 비밀번호를 찾아냅니다
• 무엇부터 고쳐야 할지 보여 주고, 항목마다 변경 버튼 제공
• 점검은 휴대폰 안에서만 이루어지며, 어디로도 전송되지 않습니다

■ 다른 앱에서도 비밀번호 자동 완성
• Android 자동 완성을 지원하는 앱과 브라우저에 저장한 로그인 정보 입력
• 다른 곳에 로그인할 때 비밀번호 관리자를 열지 않고도 새 로그인 정보 저장
• 지문, 얼굴 인식 또는 화면 잠금으로 확인하기 전에는 아무것도 입력되지 않습니다

■ 암호화된 백업 파일
• 비밀번호를 암호화된 파일 하나로 백업하고, 백업 전용 비밀번호로 잠급니다(Argon2id + AES-256-GCM)
• 보관 위치는 자유롭게: 휴대폰, 컴퓨터, 평소 쓰는 드라이브 등
• 새 휴대폰에서 복원하면 없는 항목만 추가하고, 아무것도 삭제하지 않습니다

■ 간편한 비밀번호 수첩
• 검색과 첫 글자 아이콘이 있는 깔끔한 목록. 서랍 속에서 잃어버릴 일 없는 비밀번호 수첩
• 입력하는 동안 사이트 이름 추천
• 아이디 칸이 이메일, 전화번호, 고객 번호, Wi-Fi 네트워크 이름에 맞춰 바뀝니다
• 라이트 테마와 다크 테마
• 앱을 열 때마다 보안에 관한 짧은 명언 표시
• 일상 메모를 위한 메모 공간(메모 공간은 암호화되지 않으니, 비밀 정보는 각 비밀번호의 암호화된 메모에 적어 두세요)

■ 이런 분께 추천합니다
• 비밀번호를 클라우드 서비스에 맡기지 않고 기기 안에서 관리하고 싶은 분
• 수첩, 메모 앱, 어디서나 같은 비밀번호에 지친 분
• 은행, 이메일, Wi-Fi, 간편결제 로그인 정보를 오프라인 비밀번호 금고 하나에 모아 두고 싶은 가족과 작은 가게

■ 이런 기능은 없습니다
클라우드 동기화도 계정도 없기 때문에 비밀번호 금고는 휴대폰 한 대에만 있습니다. 백업 파일을 안전한 곳에 보관해 주세요. Bimir Lock은 유출된 비밀번호 목록과 대조하지 않으며, 2단계 인증(2FA) 코드도 만들지 않습니다. 앱 화면은 현재 영어로 제공됩니다.

무료이며 광고, 구독, 인앱 결제가 없습니다. 네팔 포카라의 1인 개발자가 만든 오프라인 비밀번호 관리자입니다.
