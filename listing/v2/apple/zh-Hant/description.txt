Bimir Lock 是一款離線密碼管理 App，將你的密碼加密儲存在你自己的 iPhone 或 iPad 上。不必建立帳號、不必信任雲端，也沒有廣告。每筆登入資訊只要儲存一次，就能用 PIN 碼或 Face ID 開啟，再透過自動填寫輸入。

【密碼只留在你的裝置上】
• 密碼和它的備註，都會在儲存前以 AES-256-GCM 加密
• 金鑰保存在 iOS Keychain 中，僅限本裝置使用，絕不同步
• 不必註冊、不必提供 Email、沒有伺服器：根本沒有可以被入侵的帳號
• 離線也能使用全部功能：在飛機上、在國外，或關閉行動數據時都沒問題
• 沒有廣告、沒有分析工具、沒有追蹤

【只有你能開啟】
• 每筆已儲存的密碼都只能用 6 位數 PIN 碼開啟；開啟設定後，也能使用 Face ID 或 Touch ID
• 不接受 123456、111111 這類容易被猜到的 PIN 碼
• 連續輸錯 7 次 PIN 碼，數字鍵盤就會鎖定：先是 30 秒，接著是 1、5、15 分鐘
• 「PIN 錯誤警示」會列出每一次鎖定紀錄，還能拍下嘗試猜密碼的人（選用；照片只存在你的裝置裡）
• 顯示的密碼 30 秒後會自動隱藏，複製的密碼 30 秒後會從剪貼簿清除

【幫你產生高強度密碼】
• 密碼產生器，長度 8 到 64 個字元，可自由選擇是否包含數字和符號
• 自動排除 l、I、O、0 這類容易看錯的字元
• 每組密碼都有強度指標
• 當你要重複使用已儲存的密碼時，會事先提醒你

【密碼健檢】
• 找出強度不足的密碼，以及在多個網站重複使用的密碼
• 告訴你該先修改哪一個，每一項都附有「變更」按鈕
• 全程在裝置上檢查，不會傳送任何資料

【自動填寫】
• Bimir Lock 可在 Safari 和其他 App 中，作為密碼自動填寫的提供者
• 在 iPhone「設定」的「自動填寫與密碼」中開啟
• 必須先通過 Face ID、Touch ID 或裝置密碼驗證，才會填入任何內容

【由你掌控的備份】
• 備份成一個加密檔案，並以專屬的備份密碼保護（Argon2id + AES-256-GCM）
• 想存哪裡都可以：「檔案」App、iCloud 雲碟或電腦
• 在新 iPhone 上還原時，只會補上缺少的項目，絕不刪除任何資料

【沉穩簡潔，輕鬆上手】
• 清爽的清單，支援搜尋和首字母圖示
• 輸入時自動建議網站名稱
• 使用者名稱欄位會依內容切換：Email、手機號碼、客戶編號或 Wi-Fi 網路名稱
• 淺色與深色主題
• 每次開啟時顯示一句簡短的資安名言
• 附有日常記事空間（記事不會加密，機密資訊請寫在各筆密碼的加密備註中）

【它做不到的事】
沒有雲端同步，也沒有帳號，所以你的密碼庫只存在於一台裝置上：請把備份檔案存放在安全的地方。Bimir Lock 不會比對外洩密碼清單，也不會產生雙重驗證（2FA）驗證碼。目前 App 介面為英文。
